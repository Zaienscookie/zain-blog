LVGL CMake INTERFACE_INCLUDE_DIRECTORIES 报错修复方案（Windows模拟器）

LVGL · CMake · Windows 模拟器LVGL · CMake · Windows simulatorLVGL · CMake · Windows симулятор

在 Windows 环境下编译 LVGL PC 模拟器项目时，遇到 INTERFACE_INCLUDE_DIRECTORIES 路径报错。分析发现，问题源于 port 工程直接添加裸绝对路径，未使用 $<BUILD_INTERFACE> 生成器表达式包裹，而 LVGL 底层启用了库安装导出校验。解决方案：注释 main.cmake 末尾的 INSTALLATION 代码块，删除 build 缓存后重新编译即可。Fix for the CMake INTERFACE_INCLUDE_DIRECTORIES error when building the LVGL PC simulator on Windows. The issue comes from raw absolute paths in the port project not wrapped in $<BUILD_INTERFACE>, combined with LVGL's install-export check. Solution: comment out the INSTALLATION block in main.cmake and rebuild.Исправление ошибки CMake INTERFACE_INCLUDE_DIRECTORIES при сборке LVGL PC-симулятора в Windows. Проблема в «сырых» абсолютных путях в port-проекте и проверке установки/экспорта LVGL. Решение: закомментировать блок INSTALLATION в main.cmake и пересобрать.
